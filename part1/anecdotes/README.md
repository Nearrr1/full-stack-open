# Exercises 1.12 - 1.14: Anecdotes

This application was bootstrapped with [Vite](https://vite.dev/) and React for [Full Stack Open - Part 1](https://fullstackopen.com/en/part1/a_more_complex_state_debugging_react_apps#exercises-1-6-1-14).

## Exercises Completed

- **1.12*: anecdotes step1**: Displays a random anecdote from the array upon clicking the "next anecdote" button.
- **1.13*: anecdotes step2**: Stores votes for each anecdote in an array state, allowing users to vote for the currently displayed anecdote without mutating state directly.
- **1.14*: anecdotes step3**: Identifies and renders the anecdote with the highest number of votes in a separate section.

## Running Locally

```bash
pnpm install
pnpm dev
```
