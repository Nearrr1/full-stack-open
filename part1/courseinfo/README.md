# Exercises 1.1 - 1.2: Course Information

This application was bootstrapped with [Vite](https://vite.dev/) and React for [Full Stack Open - Part 1](https://fullstackopen.com/en/part1/introduction_to_react#exercises-1-1-1-2).

## Exercises Completed

- **1.1: course information, step1**: Refactored the app into three components: `Header`, `Content`, and `Total`.
- **1.2: course information, step2**: Refactored `Content` to use three separate `Part` components to render each part's title and number of exercises.

## Running Locally

```bash
npm install
npm run dev
```
