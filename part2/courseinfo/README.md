# Exercises 2.1 - 2.5: Course Information

This application was bootstrapped with [Vite](https://vite.dev/) and React for [Full Stack Open - Part 2](https://fullstackopen.com/en/part2/rendering_a_collection_modules#exercises-2-1-2-5).

## Exercises Completed

- **2.1: Course information step 6**: Created a `Course` component containing `Header` and `Content` (with multiple `Part` components). Key attributes are properly assigned using each part's `id`.
- **2.2: Course information step 7**: Displayed the sum of exercises for each course.
- **2.3*: Course information step 8**: Calculated the sum of exercises using the array `reduce` method.
- **2.4: Course information step 9**: Extended the application to render an arbitrary list of courses dynamically from an array.
- **2.5: Separate module step 10**: Moved `Course` and its subcomponents into a separate module (`src/components/Course.jsx`) and imported it in `App.jsx`.
